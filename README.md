# Wanderlog

A travel journal site built as part of the CodGen Frontend Internship.

## Week 1 — Foundations & Page Structure

Wanderlog is a simple travel journal homepage built using HTML and CSS.

### Features

- Semantic HTML5 structure
- Header and navigation
- Homepage hero section
- Custom typography using Google Fonts
- Flexbox header layout
- Responsive mobile layout
- Call-to-action button

### Technologies

- HTML5
- CSS3
- Google Fonts
